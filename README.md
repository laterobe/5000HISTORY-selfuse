# 5000HISTORY-selfuse
它把从夏到新中国 17 个朝代 的疆域、人物与文物，做成了一个打开浏览器就能进的世界。首页是一张会变的地图，切换朝代，疆域随之伸缩，文物、时间线、核心城市与古战场一并浮现；点进任何一个朝代，是四个阶段的故事长卷，配乐、朗读、放大镜与灯箱，读起来像一部属于那个朝代的片子。  但真正让它不只是"读"的，是后面那一层。你可以接下一个身份，和大禹一起治水，在汴京虹桥边跟掌柜、卖花女、赶考的书生喝一夜酒；可以接下 NPC 贴在告示板上的任务，用真实的几分钟换一份历史里的营生；可以把 1733 个成就、186 个古风称号 一个个点亮，在 170 道问答里被自己的记忆难住，成就够了还能反过来出题考别人；也可以走进穿越大厅，看别人怎么设想穿越，或者写下自己那一版。
